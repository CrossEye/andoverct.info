How saving and sharing work

Everything you type is saved automatically in this browser (keyed by town name), so you can close the page and come back.

Download this page with data produces a copy of this HTML file with the current numbers embedded. Email it to anyone; when they open it, they see your numbers and can keep updating their own copy. If their browser already has saved data for the same town, the page loads whichever copy was saved more recently and offers the other.

Download an empty copy is for another town: it keeps the early voting dates and Election Day but no town name, counts, or voter totals. Open it, type the town name, and start entering.

Download CSV exports the same data as a spreadsheet-friendly file. Import CSV replaces the current data with a CSV exported from this page.

For a final report after the election, fill in the absentee and Election Day rows and select everything.
