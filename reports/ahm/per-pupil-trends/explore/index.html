Explore the Per-Pupil Data

The interactive companion to Spending, Students, and Per-Pupil Costs: pick a town, a regional district, or build your own region, and see the same map, chart, and table the report uses — from the same data and the same code.

Click any town on the map to start a custom selection; click again to remove it. Selecting a town that belongs to a regional district brings the whole district along — that keeps every student and dollar counted exactly once.

About this tool. Every figure is computed in your browser from the report's published data files (dataset.json, cpi_fy.json) using the same rendering code that built the report, so the two cannot disagree. Methodology, caveats, and sources are documented in the report. Maintained by Scott Sauyet; not an official town document.
